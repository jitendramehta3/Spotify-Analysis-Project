# \# Spotify Streaming Analysis

# 

# A beginner-level data analytics project exploring Spotify songs and their performance across music platforms. The project uses Python for data cleaning and exploration, PostgreSQL for SQL analysis, and Power BI for an interactive dashboard.

# 

# \## Project Overview

# 

# The dataset contains \*\*4,598 tracks\*\* and includes song, artist, album, streaming, popularity, and platform metrics. The Power BI dashboard provides a quick overview of the dataset and lets users explore results by release year.

# 

# \## Tools Used

# 

# \- \*\*Python:\*\* Data inspection, cleaning, and exploratory analysis

# \- \*\*PostgreSQL:\*\* Data storage and SQL analysis

# \- \*\*Power BI Desktop:\*\* KPI cards, charts, and release-year slicer

# 

# \## Dashboard Highlights

# 

# \- Total tracks

# \- Total Spotify streams

# \- Total YouTube views

# \- Total TikTok views

# \- Average Spotify popularity

# \- Top 10 artists by total Spotify streams

# \- Top 10 tracks by Spotify streams

# \- Top albums by average track score

# \- Explicit vs non-explicit track distribution

# \- Spotify streams and track count by release year

# \- Release-year slicer

# 

# \## Data Cleaning

# 

# The dataset was checked for duplicate rows and missing values. Exact duplicate rows were removed during cleaning. Missing values were reviewed by column and kept where a missing value did not mean zero. The fully blank `TIDAL Popularity` column was removed from the cleaned dataset.

# 

# \## Key Files

# 

# \- `Most Streamed Spotify Songs 2024.csv` — original dataset

# \- `spotify\_cleaned.csv` — cleaned dataset used for analysis

# \- `spotify\_analysis.sql` — SQL queries used in PostgreSQL

# \- `Spotify Songs Analysis.pbix` — Power BI dashboard

# \## Notes

# 

# Spotify streams, YouTube views, and TikTok views are different metrics. Their totals are shown as separate platform figures and should not be treated as a direct like-for-like comparison. Missing values were not automatically replaced with zero.
